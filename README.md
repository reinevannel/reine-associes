# 🌹 Reine & Associés — Site vitrine bilingue (FR / EN)

Un projet **front-end & UX/UI** conçu comme une véritable commande professionnelle :  
architecture, wireframes, identité, interactions, développement…  
Un cabinet d’avocats **fictif**, mais une démarche **réelle**, précise, exigeante.

✨ *Certification Front-End — Codecademy*  
✨ Site statique, interface dynamique, sans backend.

> ⚖️ Tous les noms, dossiers, témoignages et coordonnées sont **entièrement fictifs**.  
> Un exercice de démonstration — pas un cabinet réel.

---

## 🎯 Vision & intention

Ce projet explore la rencontre entre **rigueur juridique**, **sobriété visuelle**, et **expérience utilisateur rassurante**.

| Domaine | Travail réalisé |
|--------|------------------|
| 🎨 **UX/UI** | Recherche, architecture, hiérarchie visuelle |
| 💻 **Front-end** | Intégration responsive, interactions JS, i18n FR/EN |
| ♟️ **Branding** | Identité inspirée des échecs : stratégie, maîtrise, précision |
| ♿ **Accessibilité** | Contrastes, focus visible, navigation clavier, reduced motion |

🎯 **Objectif :** créer un site vitrine crédible, élégant, et suffisamment solide pour ressembler à une vraie commande client.

---

## 🧩 Processus UX/UI

### 1. 🔍 Recherche & cadrage  
- Analyse de sites de cabinets d’avocats  
- Définition d’un univers haut de gamme, sobre, rassurant  
- Arborescence claire : stratégie → expertises → victoires → contact  

### 2. ✏️ Wireframes  
- Basse fidélité pour tester la structure  
- Hiérarchie visuelle et parcours utilisateur  
- Optimisation mobile / desktop  

### 3. 🎨 UI Design  
- Palette **bordeaux / or / encre**  
- Typographies : *Playfair Display*, *DM Sans*, *DM Mono*  
- Découpes `clip-path`, cartes, onglets sobres  
- Icônes SVG minimalistes (♟️ pièces d’échecs, ⚖️ symboles juridiques)

### 4. 📐 Design system  
- Couleurs, typographies, espacements  
- Composants réutilisables  
- Labels FR / EN  
- Cohérence globale, du premier pixel au dernier détail

## 💻 Développement front-end

### Technologies

| Techno | Rôle |
|--------|------|
| 🧱 **HTML5** | Structure sémantique |
| 🎨 **CSS3** | Grid, flexbox, custom properties |
| ⚙️ **JavaScript vanilla** | IIFE — i18n, UI, canvas, formulaire |
| 🔤 **Google Fonts** | Playfair Display, DM Sans, DM Mono |

Aucune dépendance de build → site léger, rapide, maîtrisé.

### Fonctionnalités
- 🌐 Bascule FR / EN sans rechargement (`localStorage`)  
- ⏳ Préchargeur avec bouton « Passer »  
- 📌 Navigation sticky + menu mobile (Escape)  
- 📈 Méthode en 6 étapes avec progression au scroll  
- 🗂️ Onglets d’expertises (navigation clavier complète)  
- 📁 Études de cas en accordéon  
- 💬 Témoignages interactifs  
- 📨 Formulaire de contact (validation HTML5, succès simulé)  
- ⚖️ Mentions légales en `<dialog>`  
- 🌌 Fond canvas discret (pause hors onglet / reduced-motion)

### Accessibilité
- 🔗 Lien d’évitement  
- ✨ `:focus-visible`  
- 🌙 `prefers-reduced-motion`  
- 🧩 `inert` pendant le préchargeur  
- 🎯 Cibles tactiles ≥ 44 px  
- 🧭 Attributs `aria-*` pour chaque composant interactif
