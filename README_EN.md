# 🌹 Reine & Associés — Bilingual showcase website (FR / EN)

A **front-end & UX/UI** project crafted as a real professional commission:  
architecture, wireframes, identity, interactions, development…  
A **fictional** law firm, built with real care, precision, and intention.

✨ *Front-End Certification — Codecademy*  
✨ Static website, dynamic interface, no backend.

> ⚖️ All names, cases, testimonials, and contact details are **entirely fictional**.  
> Demonstration project — not a real law firm.

---

## 🎯 Vision & intention

This project explores the balance between **legal rigor**, **visual sobriety**, and a **calm, reassuring user experience**.

| Domain | Work delivered |
|--------|----------------|
| 🎨 **UX/UI** | Research, architecture, visual hierarchy |
| 💻 **Front-end** | Responsive integration, JS interactions, FR/EN i18n |
| ♟️ **Branding** | Chess-inspired identity: strategy, mastery, precision |
| ♿ **Accessibility** | Contrast, keyboard navigation, reduced motion |

🎯 **Goal:** build a credible, elegant showcase website that feels like a real client project.

---

## 🧩 UX/UI Process

### 1. 🔍 Research & framing  
- Analysis of law firm websites  
- Definition of a high-end, calm, trustworthy identity  
- Clear structure: strategy → expertise → victories → contact  

### 2. ✏️ Wireframes  
- Low-fidelity wireframes to test structure  
- Visual hierarchy and user flow  
- Mobile / desktop optimization  

### 3. 🎨 UI Design  
- **Burgundy / gold / ink** palette  
- Typography: *Playfair Display*, *DM Sans*, *DM Mono*  
- `clip-path` shapes, clean cards, minimal tabs  
- SVG icons (♟️ chess pieces, ⚖️ legal symbols)

### 4. 📐 Design system  
- Colors, typography, spacing  
- Reusable components  
- FR / EN labels  
- Cohesive experience from first pixel to last detail

## 💻 Front-end development

### Technologies

| Tech | Role |
|------|------|
| 🧱 **HTML5** | Semantic structure |
| 🎨 **CSS3** | Grid, flexbox, custom properties |
| ⚙️ **Vanilla JavaScript** | IIFE — i18n, UI, canvas, form |
| 🔤 **Google Fonts** | Playfair Display, DM Sans, DM Mono |

No build dependencies → lightweight, fast, controlled.

### Features
- 🌐 FR / EN switch without reload (`localStorage`)  
- ⏳ Preloader with “Skip” button  
- 📌 Sticky navigation + mobile menu (Escape)  
- 📈 Six-step method with scroll progression  
- 🗂️ Expertise tabs (full keyboard navigation)  
- 📁 Case studies in accordion  
- 💬 Interactive testimonials  
- 📨 Contact form (HTML5 validation, simulated success)  
- ⚖️ Legal notice in native `<dialog>`  
- 🌌 Subtle canvas background (paused off-tab / reduced-motion)

### Accessibility
- 🔗 Skip link  
- ✨ `:focus-visible`  
- 🌙 `prefers-reduced-motion`  
- 🧩 `inert` during preloader  
- 🎯 Touch targets ≥ 44 px  
- 🧭 `aria-*` attributes across all components
